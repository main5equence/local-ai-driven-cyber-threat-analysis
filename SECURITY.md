# Security Policy

## Supported Versions

This project is currently maintained for educational and research purposes only.

---

# Security Considerations

Local AI-driven Cyber-Threat Analysis is designed as a local-first cybersecurity monitoring platform.

The project:
- runs locally on localhost,
- uses locally hosted AI models through Ollama,
- stores incidents inside a local SQLite database,
- does not intentionally send network traffic or threat data to external cloud services.

---

# Responsible Usage

This project is intended strictly for:
- educational purposes,
- cybersecurity learning,
- local threat analysis,
- research and experimentation.

Do not use this project:
- on networks you do not own or have permission to analyze,
- for unauthorized scanning or monitoring,
- for offensive security activities against third parties.

---

# Data & Privacy

The project may process:
- local network metadata,
- packet information,
- generated threat alerts,
- simulated cybersecurity incidents.

Before publishing screenshots, logs, or demo data:
- remove or anonymize IP addresses,
- avoid exposing sensitive network information,
- avoid uploading local databases or alert logs to public repositories.

---

# Local AI Processing

AI threat analysis is performed locally using:
- Ollama
- Local LLMs (e.g. Mistral)

No external AI APIs are required by default.

---

# Reporting Security Issues

If you discover a security issue or vulnerability related to this project, please open a GitHub issue or contact the repository owner responsibly.
